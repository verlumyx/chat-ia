# Guía de Soporte Técnico y Accesos - Novatech

## Restablecimiento de Contraseñas
Si olvidaste tu contraseña o tu cuenta se encuentra bloqueada:
1. Dirígete a `https://auth.novatech.internal/reset`.
2. Ingresa tu correo corporativo (`@novatech.com`).
3. Confirma la solicitud mediante el código de un solo uso enviado a tu aplicación de doble factor (Google Authenticator o 1Password).
4. La nueva contraseña debe tener al menos 14 caracteres, combinando mayúsculas, minúsculas, números y caracteres especiales.

## Conexión a la VPN Corporativa
Para acceder a los entornos de staging, bases de datos internas y servicios protegidos:
- Descarga e instala el cliente **WireGuard** o **Tailscale** según las instrucciones enviadas en tu kit de bienvenida.
- Inicia sesión con el Single Sign-On (SSO) de Google Workspace con tu cuenta de Novatech.
- Si experimentas problemas de latencia o desconexión recurrente, asegúrate de deshabilitar resolvers DNS personalizados y reporta un ticket en el canal de Slack `#it-helpdesk`.

## Software y Licencias Disponibles
Cada ingeniero y empleado cuenta con acceso automático o previa solicitud a las siguientes herramientas:
- **Comunicación:** Slack corporativo y Google Meet.
- **Gestión de proyectos:** Jira y Notion.
- **Desarrollo:** GitHub Enterprise, Copilot / Gemini Code Assist, y cuentas sandbox en AWS y Supabase.
- **Solicitudes especiales:** Para licencias adicionales de software (ej. Figma Pro, DataDog), abre una solicitud en el portal de compras internas con aprobación de tu manager.
